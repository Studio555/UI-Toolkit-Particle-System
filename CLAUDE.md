# UI Toolkit Particle System

Unity package and sample project for particle effects authored through UI Builder.

- `README.md` documents features, dependencies, and installation.
- `Packages/UIToolkitParticleSystem/` contains the package source.
- `Assets/` contains project assets; `Docs/` contains documentation images.
- Check `ProjectSettings/ProjectVersion.txt` and `Packages/manifest.json` before opening the project in Unity.
